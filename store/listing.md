```
📍 내 주변 로또 명당, 지도에서 바로 찾기

「로또 명당 지도」는 동행복권 공식 당첨 판매점 데이터를 바탕으로 전국의 로또 6/45 1등·2등 배출점을
지도 위에 보여주는 앱입니다. 회원가입도, 로그인도 필요 없습니다.

✨ 주요 기능

• 명당 지도
  262회(2007년)부터 최신 회차까지 1등을 배출한 판매점을 지도에 핀으로 표시합니다.
  핀의 숫자는 1등 배출 횟수. 지도를 확대하면 개별 판매점이, 축소하면 지역별로 묶여 보입니다.

• 내 주변 명당
  "내 위치" 버튼 한 번으로 내가 있는 곳 주변의 명당을 바로 확인하세요.

• 명당 랭킹
  1등 배출 횟수 순 전국 랭킹. 시·도 필터, 최근 1년/3년/5년 기간 필터, 상호·주소 검색을 지원합니다.

• 당첨 이력
  판매점마다 몇 회차에 몇 등이 나왔는지, 자동·수동 여부까지 한눈에.

• 내 메모 & 즐겨찾기
  다녀온 명당에 평점, 방문일, 자유 메모를 남겨 두세요. "주차 가능", "토요일 오후 줄 김" 같은
  나만의 기록이 다음 방문 때 도움이 됩니다. 즐겨찾기한 판매점은 지도에서 빨간 테두리로 표시됩니다.

• 길찾기 · 전화
  판매점 상세에서 바로 지도 앱으로 길찾기, 전화 걸기.

• 최신 회차 자동 반영
  앱을 열 때마다 새 회차의 당첨 판매점을 자동으로 받아옵니다.

• 오늘의 행운 번호
  재미로 뽑아 보는 무작위 번호 6개. 하루 한 번 무료.
```

### 콘텐츠 등급 설문 (IARC)
- 카테고리: **유틸리티, 생산성, 커뮤니케이션 또는 기타**
- 도박 관련 항목: "실제 도박을 하거나 현금을 걸 수 있나요?" → **아니요**.
  "도박 관련 정보/콘텐츠(복권 판매점 위치·당첨 이력)를 다루나요?" 류 문항이 있으면 **예**로 정직하게 답한다.
  (앱 안에서 복권을 사거나 돈을 걸 수는 없음)
- 폭력/성적/약물: 모두 **아니요**
- 사용자 간 상호작용, 개인정보 공유: **아니요**
- 위치 공유: **아니요** (내 위치는 기기 안에서만 사용, 다른 사용자에게 공유 안 함)
- 디지털 상품 구매: **아니요**

### 데이터 보안 양식
- 데이터를 수집하거나 공유하나요? → **예** (AdMob SDK 때문에)
- 수집 데이터 유형:
  - **기기 또는 기타 ID** → 광고 ID. 목적: 광고 또는 마케팅. 필수. 공유: 예(Google AdMob).
  - **앱 활동 → 앱 상호작용** → 광고 노출/클릭. 목적: 광고 또는 마케팅, 분석. 공유: 예.
  - **위치 → 대략적/정확한 위치**: 기기에서만 처리되고 전송되지 않으므로 "수집"에 해당하지 않음.
    (Google 정책상 기기를 떠나지 않는 데이터는 수집으로 보지 않음. 단, 지도 타일 요청으로 대략적인 조회 영역이 지도 서버에 가므로
    보수적으로 "대략적인 위치 — 앱 기능 — 임시 처리" 로 신고해도 됨)
- 암호화 전송: **예**
- 삭제 요청 가능: 예 (앱 내 전체 삭제 / 앱 삭제 / 광고 ID 재설정)
- 메모·즐겨찾기는 기기 내부에만 저장되고 **전송되지 않으므로 "수집"에 해당하지 않음**
